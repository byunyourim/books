### 객체 지향의 핵심 : 역할, 책임, 협력

### 개념 정리

#### 협력
- 여러 객체가 상호작용하여 하나의 기능을 수행하는 것

#### 책임
- 객체가 협력을 위해 수행하는 로직이나 행위 집합
- doing & knowing
- 무엇을 할 수 있는지? 알고 있는지

#### 역할
- 협력안에서 객체가 수행하는 책임의 집합으로 특정 행동을 담당
- 객체가 아닌, 역할에 책임을 부여
- 같은 역할을 여러 객체가 수행할 수 있음
- 누가 그 일을 담당하니?
  
#### 메시지
- 객체들이 협력하기 위해 사용하는 의사소통 수단


<br>

### 예시

**책임과 역할?**
- 요리사는 역할로, 여러 명의 요리사가 있을 수 있음
- 요리하기는 요리사가 반드시 해야하는 일로 책임이다. 


<br>

#### 온라인 쇼핑
- **협력**: 사용자가 상품을 선택하여 장바구니에 넣고 결제한다.
- **책임**
  - 상품: 가격 정보를 알고 있음 (knowing)
  - 장바구니: 상품 추가, 총액 계산 (doing)
  - 결제 시스템: 결제 처리 (doing)
- **역할**
  - 상품: 가격 정보 제공
  - 장바구니: 상품 추가 및 총액 관리
  - 결제 시스템: 결제 처리



---

### 메시지는 객체를 결정하고, 행동은 상태를 결정한다.

#### 메시지는 객체를 결정한다.
- 메시지는 객체에게 요청하는 신호로 객체 간의 상호작용은 메시지를 통해 이루어진다.
- **즉, 어떤 메시지를 주고 받냐에 따라 해당 역할을 수행할 객체가 결정됨.**
  - 결제해줘 -> 결제 시스템 객체가 처리
  - 상품 추가해줘 -> 장바구니 객체가 처리 


#### 행동은 상태를 결정한다.
- 행동은 객체가 메시지를 받고 실행하는 로직 (메서드)
- 행동을 하면 객체의 상태가 변한다
  - 주문 생성 (created)
  - 결제 완료  created -> paid
  - 상품 발송  paid -> shipped
