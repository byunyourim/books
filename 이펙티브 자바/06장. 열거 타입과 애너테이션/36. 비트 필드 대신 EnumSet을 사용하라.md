```java
public class Text {
    public static final int BOLD = 1 << 0;
    public static final int ITALIC = 1 << 1;
    public static final int UNDERLINE = 1 << 2;
    public static final int STRIKETHROUGH = 1 << 3;

    public void applyStyles(int styles) {
         // 생략
    }

    public static void main(String[] args) {
        Text text = new Text();

        int styles = BOLD | UNDERLINE;
        text.applyStyles(styles);
    }
}
```
비트 필드는 여러 개의 상수를 하나의 정수 값으로 결합할 때 사용되는 기법이다.  
각 상수는 정수의 특정 비트에 대응하고, 이 비트들은 OR 연산자로 결합하여 여러 상수를 하나의 값으로 표현한다.

위의 방식은 styles값을 비트 연산자로 결합해서 여러 스타일을 하나의 값으로 다루는데, 이 값이 0101처럼 보이면 해석이 어렵다.

### EnumSet
내부적으로 비트 벡터를 사용해서 Enum 상수를 저장하기 때문에 빠르ㄷ.


이때, EnumSet를 사용하면 더 쉽게 관리 가능함

```java
public class Text {
    public enum Style {
        BOLD, ITALIC, UNDERLINE, STRIKETHROUGH
    }

    public void applyStyles(Set<Style> styles) {
        System.out.printf("Applying styles %s to text%n",
                Objects.requireNonNull(styles));
    }

    public static void main(String[] args) {
        Text text = new Text();

        Text text = new Text();
        text.applyStyles(EnumSet.of(Style.BOLD, Style.ITALIC));
    }
}
```


#### of() 메서드
주어진 Enum상수를 포함하는 집합을 반환한다.
```java
EnumSet<Day> mondaySet = EnumSet.of(Day.MONDAY);
System.out.println(mondaySet);  // [MONDAY]
```

```java
public static <E extends Enum<E>> EnumSet<E> of(E first, E... rest) {
    EnumSet<E> result = noneOf(first.getDeclaringClass());
    result.add(first);
    for (E e : rest)
        result.add(e);
    return result;
}
```

#### noneOf() 메서드
지정한 Enum 클래스의 빈 집합을 반환한다.
64개 이하면 RegularEnumSet, 이상이면 JumboEnumSet
```java
public static <E extends Enum<E>> EnumSet<E> noneOf(Class<E> elementType) {
    Enum<?>[] universe = getUniverse(elementType);
    if (universe == null)
        throw new ClassCastException(elementType + " not an enum");

    if (universe.length <= 64)
        return new RegularEnumSet<>(elementType, universe);
    else
        return new JumboEnumSet<>(elementType, universe);
}
```

### EnumSet, HashSet

EnumSet은 내부적으로 비트맵을 사용하여 Enum 상수들을 저장한다. 
비트맵 방식은 메모리를 사용이 적고, 원소가 많지 않으면 한 개의 long 변수로 모든 상수의 포함 여부를 저장할 수 있다. 
반면, HashSet은 각 Enum 상수를 객체로 저장하게 되므로 메모리 소모가 더 많다.

그리고, EnumSet은 Enum타입의 상수만 저장할 수 있다. 따라서 타입 안전이 보장됨  

EnumSet은 Enum 전용 Set이기 때문에, 코드에서 Enum 상수들을 다룰 때 코드가 더 명확하고, HashSet을 사용할 경우, Enum 상수들을 담을 수 있지만 Set이 Enum 전용임을 명시적으로 표현이 어렵다.

### 정리
EnumSet 클래스는 비트 필드 수준의 명료함과 성능을 제공하고 아이템 34에서 설명한 열거 타입의 장점까지 갖는다.
EnumSet의 유일한 단점이라면 (자바 9까지는 아직) 불변 EnumSet을 만들 수 없다는 것이다. 
그 부분은 Collections.unmodifiableSet으로 EnumSet을 감싸 사용할 수 있다.
