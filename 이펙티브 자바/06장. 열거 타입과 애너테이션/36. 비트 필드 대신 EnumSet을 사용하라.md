```java
public class Text {
    public static final int BOLD = 1 << 0;
    public static final int ITALIC = 1 << 1;
    public static final int UNDERLINE = 1 << 2;
    public static final int STRIKETHROUGH = 1 << 3;

    public void applyStyles(int styles) {
         // 생략
    }

    public static void main(String[] args) {
        Text text = new Text();

        int styles = BOLD | UNDERLINE;
        text.applyStyles(styles);
    }
}
```
비트 필드는 여러 개의 상수를 하나의 정수 값으로 결합할 때 사용되는 기법이다.  
각 상수는 정수의 특정 비트에 대응하고, 이 비트들은 OR 연산자로 결합하여 여러 상수를 하나의 값으로 표현한다.

위의 방식은 styles값을 비트 연산자로 결합해서 여러 스타일을 하나의 값으로 다루는데, 이 값이 0101처럼 보이면 해석이 어렵다.



이때, EnumSet를 사용하면 더 쉽게 관리 가능함

```java
public class Text {
    public enum Style {
        BOLD, ITALIC, UNDERLINE, STRIKETHROUGH
    }

    public void applyStyles(Set<Style> styles) {
        System.out.printf("Applying styles %s to text%n",
                Objects.requireNonNull(styles));
    }

    public static void main(String[] args) {
        Text text = new Text();

        Text text = new Text();
        text.applyStyles(EnumSet.of(Style.BOLD, Style.ITALIC));
    }
}
```

---

### 정리
EnumSet 클래스는 비트 필드 수준의 명료함과 성능을 제공하고 아이템 34에서 설명한 열거 타입의 장점까지 갖는다.
EnumSet의 유일한 단점이라면 (자바 9까지는 아직) 불변 EnumSet을 만들 수 없다는 것이다. 
그 부분은 Collections.unmodifiableSet으로 EnumSet을 감싸 사용할 수 있다.
