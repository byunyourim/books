### 인스턴스 필드를 사용하자. 
```java
enum Number {
    ZERO(0),
    ONE(1),
    TWO(2),
    THREE(3),
    FOUR(4);

    private int number;

    Number(int number) {
        this.number = number;
    }

    public int getNumber() {
        return number;
    }
}
```

### JPA 와 enum
JPA에서는 @Enumerated 어노테이션을 이용해 Enum타입을 데이터베이스 컬럼에 매핑할 수 있다. 
   

#### @Enumerated
JPA에서 Enum 필드를 데이터베이스 컬럼과 매핑할 때 사용하는 어노테이션으로, 어떤 방식으로 데이터베이스에 저장할 지 정할 수 있다.

```java
public enum Status {
    ACTIVE,
    INACTIVE
}
```
```java
@Enumerated(EnumType.STRING)
private Status status;
```
- EnumType.STRING : Enum의 이름을 컬럼 값으로 저장 (ACTIVE, INACTIVE)
- EnumType.ORDINAL : Enum의 순서를 컬럼 값으로 저장 (ACTIVE -> 0, INACTIVE -> 1)


EnumType.ORDINAL을 사용하면 Enum의 상수의 순서(ordinal 값)가 컬럼에 저장되는데, 순서가 변경되면 데이터가 잘못 해석될 위험이 있어 String을 사용하는 것이 더 안전하다.
