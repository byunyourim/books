

### 로(raw) 타입
로 타입은 제네릭 클래스나 인터페이스를 타입 매개변수 없이 사용하는 것이다. 
제네릭 타입을 하나 정의하면 그에 딸린 로 타입도 함께 정의된다.  

- List<E>의 로 타입은 List이다.

이런 로 타입은 제네릭 타입 정보가 모두 지워진 것처럼 동작한다. 
```java
List list = new ArrayList();
list.add("ab");
list.add(5);

System.out.println(list.get(0));    // ab
System.out.println(list.get(1));    // 5
```


<br>

#### 왜 Raw 타입이 존재할까?
제네릭이 도입되기 전의 코드와 하위 호화나성을 유지하기 위해 Raw 타입이 필요했다. 

제네릭 도입 이후에도 기존의 코드를 그대로 사용할 수 있어야 했기 때문에 Raw 타입을 허용하였다. 


<br>

#### 문제 
- 컴파일럭 타입 검사를 하지 않기 때문에 잘못된 타입을 넣으면 런타임에 문제가 발생한다.
```java
List list = new ArrayList();
list.add("String");
list.add(42); // 컴파일 경고 없음

// 오류 발생 가능
String str = (String) list.get(1); // ClassCastException 발생
```

값을 꺼내오기 전에는 오류를 알아차릴 수가 없다. 즉 문제 코드와 원인 제공 코드가 물리적으로 떨어져 있을 수 있어, 에러를 잡기 위해 코드 전체를 훑어봐야 할 수 있다. 

<br>
  
제네릭을 사용하면 컴파일 시점에 타입 검사가 이루어진다.

### 매개변수화 타입의 이점
#### 매개변수화 타입?
List<String> : `원소의 타입이 String인 리스트`를 의미하는 매개변수화 타입이다.  
    
위 처럼 이용하면 다른 타입의 인스턴스를 넣으려하면 컴파일 오류가 발생하여 문제를 알려준다.

### `List` 와 `List<Object>`    

        
List와 같은 로 타입은 사용하면 안되지만, List<Object>처럼 임의 객체를 허용하는 매개변수화 타입은 괜찮다.   
왜냐하면 List<Object>는 매개변수화된 타입으로, 컴파일러가 타입 검사를 수행하기 때문에 안전하다.  



     
#### `List<Object>`     

List<Object>는 특별히 모든 타입의 객체를 허용해야 하는 상황에서 사용하는 것이 좋다.  

정확히 Object 타입 또는 Object 타입을 상속받은 타입만 허용하기 때문에,
**제네릭 타입이 다른 컬렉션(List<String> 등)**은 List<Object>로 처리할 수 없다.  

```java
List<Object> objectList = new ArrayList<>();
objectList.add("String"); // 허용
objectList.add(123);      // 허용

List<String> stringList = new ArrayList<>();
printList(objectList);    // 가능
printList(stringList);    // 컴파일 에러
```

```java
void printList(List<Object> list) { 
    for (Object obj : list) { 
        System.out.println(obj);
    }
}
```

### 비한정적 와일드카드
List<Object>는 특정 상황에서는 괜찮지만, 대부분의 **와일드카드(List<?>)** 를 사용하는 것이 더 적합하다. 와일드카드는 Raw 타입보다 안전하고, 일반화된 코드를 작성할 수 있게 해준다.  

#### List<?>     
List<?>는 타입 안정성을 유지하면서, 모든 제네릭 타입을 허용한다.    
즉, List<?>는 List<String>, List<Integer>, List<Object> 등 어떤 제네릭 타입도 받을 수 있다.   

```java
void printList(List<?> list) {
    for (Object obj : list) {
        System.out.println(obj);
    }
}

List<String> stringList = new ArrayList<>();
List<Integer> intList = new ArrayList<>();
List<Object> objectList = new ArrayList<>();

printList(stringList); // 가능
printList(intList);    // 가능
printList(objectList); // 가능
```


**List<Object>** 는 Object 타입을 명시했으므로 Object 타입의 데이터를 추가할 수 있다.
**List<?>** 는 어떤 타입인지 정확히 모르기 때문에, 데이터를 추가하는 것이 금지된다(단, null은 허용).


<br>

#### 언제 `List<Object>`와 `List<?>`를 사용할까?  

- List<Object>: 모든 타입의 객체를 추가하거나 읽어야 하는 경우.
- List<?>: 리스트의 요소를 추가하지 않고, 읽거나 처리만 해야 할 때.




<br>

### instanceof와 로 타입
```java
if (o instanceof Set) {  // 로 타입
	  Set<?> s = (Set<?>) o; // 와일드카드 타입
}
```

### 마무리
로타입을 사용하면 런타임 예외가 발생할 수 있으니 사용하지 말자.

로타입의 제공이유는 제네릭이 도입되기 이전 코드와의 호환성 때문이다. 
Set<Object>는 어떤 타입의 객체도 저장할 수 있다. 
Set<?> 모종의 타입 객체만 저장할 수 있다.
