### 비검사 경고
제네릭을 사용할 때 발생하는 경고로, 컴파일러가 타입 안정성을 완전하게 보장할 수 없을때 나타난다.   
제네릭 타입에 대한 타입 검사가 런타임에 이루어지는 경우에 발생한다.  



#### 왜 발생하는지?
제네릭은 컴파일 시 타입 안정성을 제공하지만, 내부적으로는 타입 소거라는 과정을 통해 제네릭 정보를 삭제한다.  
따라서 런타임에서는 제네릭 타입 정보가 유지되지 않기 때문에, 특정 상황에서는 컴파일러가 타입 안정성을 보장할 수 없다.  
   
#### 사례
1. 비검사 형변환
아래와 같은 코드에서는 제네릭 타입 정보가 런타임에 유지되지 않으므로, List<String>인지 확신할 수 없다.
```java
List rawList = new ArrayList(); // 제네릭 타입을 지정하지 않은 raw 타입
rawList.add("hello");
rawList.add(123);

List<String> stringList = rawList; // 비검사 형변환
for (String s : stringList) {
    System.out.println(s); // ClassCastException 발생 가능
}
```
컴파일러는 rawlist를 List<String>으로 형변환하면서 비검사 경고를 발생시킨다.


2. Raw 타입 사용  
```java
List rawlist = new ArrayList<>();
rawlist.add("hello");
rawlist.add(123);

List<String> stringlist = rawlist;  // 비검사 경고
```
컴파일러는 raw 타입을 사용한 것이 안전하지 않다고 경고를 발생시킨다.  





3. 제네릭 배열 생성
자바에서는 제네릭 배열을 직접 생상하는 것을 허용하지 않는다. 하지만 형변환을 사용하면 비검사 경고가 발생한다.
```java
List<String[]> stringlists = new list[10];  // 비검사 경고
```
컴파일러는 제네릭 배열을 생성할 수 없기 때문에 경고를 발생시킨다.  


#### 비검사 경고를 제거하는 방법
1. 제네릭 타입을 명시적으로 사용
- Raw 대신 제네릭 타입을 사용하면 경고를 줄일 수 있다.
```java
List<String> list = new ArrayList<>();
list.add("hello");
```
2. @SuppressWarnings("unchecked") 사용
경고를 무시해야 하는 경우, 해당 코드에 한정하여 경고를 억제할 수 있다.

### @SuppressWarnings("unchecked")
경고를 제어하는 어노테이션으로, 컴파일러에게 특정 경고를 무시하라는 지시를 내린다. 
주로 제네릭을 사용할 때 발생하는 비검사 경고를 억제하는 데 사용된다.  
      
자바에서는 제네릭 배열을 직접 생성할 수 없다. 배열의 타입이 런타임에 타입 소거되어 제네릭 정보가 사라지기 때문에 
비검사 경고가 발생한다. 이때 사용할 수 있다.   

List<String>[] array와 같은 제네릭 배열을 생성할 때 경고가 발생하며, 이를 @SuppressWarnings("unchecked")로 억제한다.  


결고를 제거할 수는 없지만 타입이 안전하다고 확신할 수 있다면 @SuppressWarnings("unchecked")을 이용해 비검사 경고를 숨기자.    


클래스, 메서드, 필드, 생성자, 지역변수 등에 붙일 수 있다.   






#### 사용범위 : 지연변수 추가
가능한 좁은 범위에 적용하자. 

한 줄이 넘는 메서드나 생성자에 @SuppressWarnings가 달려있다면 지역변수나 아주 짧은 메서드 혹은 생성자로 옮기자.  


클래스 전체에 적용해서는 안된다. 

**ArrayList의 toArray 메서드**
```java
public <T> T[] toArray(T[] a) {
    if (a.length < size)
        // Make a new array of a's runtime type, but my contents:
        return (T[]) Arrays.copyOf(elementData, size, a.getClass());
    System.arraycopy(elementData, 0, a, 0, size);
    if (a.length > size)
        a[size] = null;
    return a;
}
```
위 코드를 컴파일하면 @copyOf()@ 부분에서 경고가 발생한다. 이 경고를 제거하려면 지역변수를 추가해야 한다.

return문에는 @SuppressWarnings("unchecked")를 다는게 불가능하다.    
       
따라서 지역변수를 추가해 @SuppressWarnings의 범위를 좁힌다.

### 마무리
비검사 경고는 중요하니까 무시하지 말자. 
런타임 ClassCastException을 일으킬 수 있는 잠재적 가능성을 뜻하니 최선을 다해서 제거하자.

경고를 없앨 방법을 못 찾겠다면, 그 코드가 타입 안전함을 증명하고 가능한 범위를 좁혀 @SuppressWarnings("unchecked) 어노테이션으로 경고를 숨기자  
그런 다음 근거를 주석으로 남겨라.
