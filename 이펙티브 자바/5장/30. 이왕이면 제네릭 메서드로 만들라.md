Collections의 알고리즘 메서드(binarySearch, sort 등)는 모두 제네릭이다.  


## 제네릭 메서드
매개변수화 타입을 받는 정적 유틸리티 메서드


`타입 매개변수 목록(<>)`은 메서드에서 어떤 제네릭 타입을 사용할지 선언하며, 메서드의 제한자와 반환 타입 사이에 위치한다.

<E>를 선언하는 이유는 컴파일러는 E가 무엇인지 알 지 못하기 때문이다. 
제네릭 메서드는 타입 매개변수를 직접 선언해야 메서드 내에서 안전하게 사용할 수 있다.

<br>

---

#### 메서드에서도 로 타입을 사용하지 말자
```java
public static Set union(Set s1, Set s2) {
    Set result = new HashSet(s1);
    result.addAll(s2);
    return result;
}
```
컴파일은 가능하지만 new HashSet 생성과정과 result에 s2를 addAll 하는 과정에서 로 타입에 대한 경고가 발생한다. 

   
```java
public static <E> Set<E> union (Set<E> s1, Set<E> s2){
    Set<E> result = new HashSet<>(s1);
    result.addAll(s2);
    return result;
}
```
위 코드는 세 개의 Set 집합의 타입이 모두 같아야 한다. 한정적 와일드카드 타입을 이용하면 더 유연하게 할 수 있다.  


<br>

## 제네릭 싱글턴 팩터리
하나의 객체를 여러 타입으로 재사용할 수 있도록 도와주는 정적 메서드  

불변 객체는 내용이 변하지 않기 때문에 타입에 상관없이 재사용이 가능하고, 제네릭은 런타임에 정보가 지워지기 때문에 같은 객체를 다른 객체 타입으로 매개변수화 할 수 있다.


#### 제네릭 싱글턴 팩터리 패턴 - 항등함수

항등함수는 객체를 변경하지 않고 그대로 반환하는 함수를 말한다. 


```java
private static UnaryOperator<Object> IDENTITY_FN = (t) -> t;

@SuppressWarinings("unchecked")
public static <T> UnaryOperator<T> identityFunction(){
    return (UnaryOperator<T>) IDENTITY_FN;
}
```
#### 제네릭 싱글턴 팩터리에서 항등함수
제네릭 싱글턴 팩터리 패턴은 여러 타입에 대해 하나의 객체를 재사용하고, 그 객체의 타입을 동적으로 지정하는 패턴이다.  
이때 항등함수를 사용하여 객체의 타입을 "변경하지 않고" 그대로 반환하는 방식으로 동작할 수 있다.
   
예를 들어, 싱글턴 객체가 있을 때, 그 객체가 여러 타입으로 사용할 수 있도록 하려면, 항등함수를 활용해 요청하는 타입으로 "변환"하거나 "새로 생성하지 않고" 이미 생성된 객체를 그대로 사용할 수 있다.

따라서 T가 어떤 타입이든 UnaryOperator<T>를 사용해도 타입 안전하기 때문에 비검사 형변환 경고를 숨겨도 된다.



<br>

## 재귀적 한정적 타입
자신이 들어간 표현식을 사용해 타입 매개변수의 허용 범위를 한정하는 개념으로, 주로 Comparable와 함께 사용된다.

```java
public interface Comparable<T>{
	int compareTo(T o);
}
```

타임 매개변수 T는 Comparable<T>를 구현한 타입이 비교할 수 있는 원소의 타입을 정의한다.

대부분 자신과 같은 타입만 비교가 가능하다.  


<br>

#### Comparable과 재귀적 타입 한정


`Comparable<T>`에서 T는 대부분의 경우 자기 자신과만 비교 가능하다. String은 String만 비교할 수 있고, Integer는 Integer만 비교할 수 있다.  

    
`Comparable<T>`를 구현한 타입의 객체들이 포함된 컬렉션에서는 정렬, 검색 등의 기능을 수행할 수 있다. 
컬렉션에 담긴 원소들은 상호 비교가 가능해야 하므로, 해당 컬렉션의 타입 매개변수는 Comparable을 구현한 타입이어야 한다.  



```java
public static <E extends Comparable<E>> E max(Collection<E> c);
```
`<E extends Comparable<E>>`는 타입 매개변수 E가 `**Comparable<E>**`를 구현한 타입이어야 한다는 의미로 모든 타입 E는 자신과 비교할 수 있어야 한다는 의미이다.  



<br>

```java
public static <E extends Comparable<E>> E max(Collection<E> c){
    if(c.isEmpty()){
       throw new IllegalArgumentException("컬렉션이 비었습니다.");
    }
        
    E result = null;
    for (E e : c){
        if(result == null || e.compareTo(result) > 0){
            result = Objects.requireNonNull(e);
        }
    }
        
    return result;
}
```
재귀적 타입 한정을 이용한 최댓값 계산 메서드로 컴파일오류나 경고는 발생하지 않으며 컬렉션에 담긴 원소의 자연적 순서를 기준으로 최댓값을 계산한다.

<br>

#### 마무리
클라이언트에서 입력 매개변수와 반환값을 명시적으로 형변환해야 하는 메서드보다 제네릭 메서드가 더 안전하며 사용하기도 쉽다.
타입과 마찬가지로, 메서드도 형변환 없이 사용할 수 있는 편이 좋으며, 많은 경우 그렇게 하려면 제네릭 메서드가 되어야 한다.
