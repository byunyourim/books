## 중첩 클래스
다른 클래스 안에 정의된 클래스로 자신을 감싼 바깥 클래스에서만 쓰여야 하고, 
그 외 쓰임이 있드면 톱레벨 클래스로 만들어야 한다.

#### 왜 사용할까?
다른 클래스와 협력할 일이 적고, 외부 클래스와 밀접한 관련이 있을 때 주로 사용한다.
중첩 클래스를 통해 불필요한 관계를 감추고 접근성을 높인다.

#### 종류
- 정적 멤버 클래스
- (비정적) 멤버 클래스
- 익명 클래스
- 지역 클래스

<br><br>

## 정적 멤버 클래스
클래스 내부에 정적으로 선언된 메서드로, 다른 클래스 내부에 선언되고, 바깥 클래스의 private 멤버에서 접근이 가능하다.
private로 선언시 바깥 클래스에서만 접근이 가능하다.
   
#### 사용
- 바깥 클래스가 표현하는 객체의 한 부분일 때


---

## (비정적) 멤버 클래스
static이 붙지 않은 멤버 클래스로 바깥 클래스의 인스턴스와 암묵적으로 연결된다. 즉, 바깥 클래스의 인스턴스가 존재해야 생성될 수 있다.   
클래스명.this 형태로 바깥 인스턴스의 메서드를 호출하거나 바깥 인스턴스의 참조를 가져올 수 있다.

```java
class Outer {
    class Inner {
        void show() {
            System.out.println("Innere class method");
        }
    }
}
Outer outer = new Outer();
Outer.Inner innere = outer.new Inner();
inner.show();
```

```java
class Outer {
    private int value = 10;

    class Inner {
        void showOuterValue() {
            System.out.println("Outer value: " + Outer.this.value);
        }
    }
}
```
비정적 멤버 클래스는 바깥 클래스의 특정 인스턴스와 항상 연결되며, 바깥 클래스가 없으면 생성할 수 없다.  

따라서 비정적 멤버 클래스는 바깥 클래스의 상태에 의존하기 때문에, 바깥 인스턴스를 참조하기 위한 참조 필드를 포함하며, 이로 인해 메모리를 더 차지하고 생성 시간이 더 오래 걸린다.

반면, 정적 멤버 클래스는 바깥 클래스의 인스턴스와 독립적으로 존재할 수 있기 때문에 가벼운 인스턴스 생성이 가능하고, 성능이 더 좋다.

따라서, 비정적 멤버 클래스는 바깥 클래스와 밀접하게 연관된 작업을 할 때 사용하고, 정적 멤버 클래스는 바깥 클래스와 독립적으로 동작할 때 사용하면 좋ㄷ.
   
#### 사용

비정적 멤버 클래스는 어댑터 패턴을 구현할 때 자주 사용된다.
어댑터 패턴은 다른 클래스의 인스턴스를 감싸서 마치 다른 클래스처럼 동작하게 만드는 방법이다.

예를 들어, Set이나 List 같은 컬렉션 클래스에서 **반복자(iterator)** 를 만들 때, 비정적 멤버 클래스를 사용하여 컬렉션의 내부 구조를 외부에서 잘 숨기면서 반복하는 역할을 한다.

즉, 비정적 멤버 클래스는 내부 클래스가 바깥 클래스의 정보를 알고 있으면서도, 바깥 클래스와 다른 방식으로 동작할 수 있도록 해준다.

## 익명 클래스
이름을 갖지 않는 클래스로 클래스의 선언과 동시에 객체를 생성 한다. 주로 일회용으로 이용할때 사용된다.
여러 인터페이스를 구현할 수 없고, 인터페이스를 구현하는 동시에 다른 클래스를 상속할 수 없다.
```java
public class AnonyEample {

    public static void main(String[] args) {
        String apple = "apple";
        Object obj = new Object() {
            @Override
            public String toString() {
                return "hello~";
            }
        };
        System.out.println(obj.toString());
    }
}
```
#### 사용
- 즉석에서 작은 함수 객체나 처리 객체를 만드는 데 주로 사용하였다.
- 람다가 이 역할을 대체

## 지역 클래스
지역변수를 선언할 수 있는 곳이면 어디든 선언이 가능하고, 유효범위도 지역 변수와 같다.
멤버 클래스처럼 이름이 존재하며, 반복적인 사용이 가능하다. 익명 클래스처럼 비 정적 문맥에서 사용될 때만
바깥 인스턴스를 참조할 수 있다. 정적 멤버는 가질 수 없으며, 가독성을 위해 짧게 작성한다.

---
## 마무리
중첩 클래스에는 네 가지가 있으며, 각각의 쓰임이 다르다. 
메서드 밖에서도 사용해야 하거나 메서드 안에 정의하기엔 너무 길다면 멤버 클래스로 만든다. 멤버 클래스의 인스턴스 각각이 바깥 인스턴스를 참조한다면 비 정적으로, 그렇지 않으면 정적으로 만들자.   
중첩 클래스가 한 메서드 안에서만 쓰이면서 그 인스턴스를 생성하는 지점이 단 한 곳이고 해당 타입으로 쓰기에 적합한 클래스나 인터페이스가 이미 있다면 익명 클래스로 만들고, 그렇지 않으면 지역 클래스로 만들자.
