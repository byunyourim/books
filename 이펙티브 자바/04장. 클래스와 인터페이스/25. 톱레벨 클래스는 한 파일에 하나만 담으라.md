

**톱레벨 클래스(Top-Level Class)** 는 중첩되지 않고 최상위에 위치 하며, 독립적으로 정의된 클래스이다.  

이번 장에서는 톱 레벨 클래스를 하나의 파일에 하나만 담자고 말하고 있다. 하나의 파일에 여러 개의 톱 클래스를 정의하게 되면 어느 것을 사용할지 컴파일 순서에 따라 달라지기 때문이다.  


<br>

#### 톱레벨 클래스 중복정의
- Utensil과 Dessert를 참조하는 Main 클래스
```java
public class Main {
    public static void main(String[] args) {
        System.out.println(Utensil.NAME + Dessert.NAME);
    }
}
```

<br><br>



#### Utensil.java
```java
class Utensil {
    static final String NAME = "pan";
}

class Dessert {
    static final String NAME = "cake";
}
```
Main을 실행 시 pancake를 출력한다.

<br><br>


똑같은 두 클래스(Utensil, Dessert)를 담은 Dessert.java
#### Dessert.java
```java
class Utensil {
    static final String NAME = "pot";
}

class Dessert {
    static final String NAME = "pie";
}
```


<br><br>



`javac Main.java Dessert.java`
- 먼저 Main.java를 컴파일한다.
- 이후 Main에서 Utensil 참조를 만나 Utensil.java 파일에 있는 Utensil과 Dessert를 모두 컴파일한다.
- 두 번째 인수로 넘어온 Dessert.java를 처리하려 할 때 같은 클래스의 정의가 이미 존재하기 때문에 컴파일 오류가 발생한다.


<br>


`javac Main.java`
- 먼저 Main.java를 컴파일한다.
- 이후 Main에서 Utensil 참조를 만나 Utensil.java 파일에 있는 Utensil과 Dessert를 모두 컴파일한다.
- pancake 출력


<br>

`javac Main.java Utensil.java`
- 먼저 Main.java를 컴파일한다.
- 이후 Main에서 Utensil 참조를 만나 Utensil.java 파일에 있는 Utensil과 Dessert를 모두 컴파일한다.
- 그리고 두 번째 명령줄 인수로 넘어온 Utensil.java를 처리하려고 할 때 정의가 이미 존재하기 때문에 컴파일 오류가 발생한다.
- pancake 출력


<br>

`javac Dessert.java Main.java`
- Dessert.java를 살펴, Utensil과 Dessert 클래스를 컴파일한다.
- Main.java를 처리할 때 Dessert.java에서 찾은 Utensil과 Dessert를 통해 값을 출력한다.
- potpie 출력





<br>

이렇게 똑같은 클래스를 중복 정의하게 되면 컴파일러 순서에 따라 동작 결과가 달라진다.  

<br>


#### 톱레벨 클래스 중복정의 해결방법
여러 개의 톱레벨 클래스들을 서로 다른 소스 파일로 분리하자.    
만약, 서로 다른 여러 톱레벨 클래스를 한 파일에 담고 싶다면 정적 멤버 클래스를 사용하자.


<br><br>


#### 톱레벨 클래스들을 정적 멤버 클래스로 변경
```java
public class Test {
    public static void main(String[] args) {
        System.out.println(Utensil.NAME + Dessert.NAME);
    }
    
    private static class Utensil{
        static final String NAME = "pan";
    }
    
    private static class Dessert{
        static final String NAME = "cake";
    }
}
```

<br>

### 마무리
소스 파일 하나에는 반드시 톱레벨 클래스(혹은 톱레벨 인터페이스)를 하나만 작성하자.
