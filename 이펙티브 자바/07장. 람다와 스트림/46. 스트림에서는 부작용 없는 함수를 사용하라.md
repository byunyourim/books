## 스트림
계산을 일련의 변환(transformation)으로 재구성하는 것으로,  
각 변환 단계는 가능한 이전 단계의 결과를 받아 처리하는 순수 함수여야 한다.


### 순수함수?
오직 입력만이 결과에 영향을 주는 함수로 입력값이 같으면 항상 같은 결과를 반환하고, 
함수 실행 중에 외부 상태를 변경하지 않는 함수이다.  

다른 가변상태 참조 하지 않고, 함수 스스로도 다른 상태를 변경하지 않는다.
예를 들어 f(x) = y 함수가 있다면, input 이 x 라면 output 은 y 이외의 값이 나오면 안된다.


### forEach
- forEach 연산은 종단 연산 중 가장 기능이 적고 덜한 스트림으로, 대놓고 반복적이라서 병렬화할 수 없다.
- 트림 계산 결과를 보고할 때만 사용하자.
- 가끔 계산 결과를 기존 컬렉션에 추가하는 등의 다른 용도로 사용 가능하다

## Collector 예제
- 일반적으로 컬렉션 객체를 생성한다.
- toList(), toSet(), toCollection(collectionFactory)

#### toList
```java
public class TestExample {
    
    Map<String, Long> freq = new HashMap<>();

    List<String> topTen = freq.keySet().stream()
            .sorted(Comparator.comparing(freq::get).reversed()) // 정렬 (비교자.역순)
            .limit(10) // 10개 제한
            .collect(Collectors.toList()); // 리스트로
}
```

#### toMap 
맵 수집기로 스트림의 각 원소가 고유한 키에 매핑되어 있을 때 적합하다.   
키가 중복되면 IllegalStateException이 발생한다.
```java
private static final Map<String, Operation> stringToEnum =
    Stream.of(values()).collect(
        toMap(Object::toString, e -> e));
```

각 키와 해당 키의 특정 원소를 연관 짓는 맵을 생성하는 예시
```java
Map<Artist, Album> topHits = albums.collect(
    toMap(Album::artist, a->a, maxBy(comparing(Album::sales))));
```

```java
toMap(keyMapper, valueMapper, (oldVal, newVal) -> newVal)
```




#### groupingBy
분류 함수(classifier)를 받고 원소들을 카테고리별로 모아 놓은 Map을 반환한다.
```java
words.collect(groupingBy(word -> alphaetize(word)));
```

- groupingBy가 반환하는 수집기가 리스트 외의 값을 갖는 맵을 생성하게 하려면, 분류 함수와 함께 다운스트림 수집기도 명시
- 다운스트림 수집기로 counting()을 건내는 방법도 있다.
```java
Map<String, Long> freq = words.collect(groupingBy(String::toLowerCase, counting())
```

#### joining
Stream의 요소를 결합하는데 사용한다.
- CharSequence 인스턴스의 스트림에만 적용 가능, 단순히 원소들은 concat 한다.
- 연결 부위에 구분 문자를 삽입해야한다. ex) ","
```java
list.stream().collect(Collectors.joining(", "));
```
