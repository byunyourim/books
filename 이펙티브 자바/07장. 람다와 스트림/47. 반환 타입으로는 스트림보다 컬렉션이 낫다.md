## Stream
for-each문은 Iterable을 순회할 때 사용되는데, Stream은 Iterable을 상속하지 않기 때문에 for-each와 호환되지 않는다  

#### 1. for-each문
```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

for (int n : numbers) {
    System.out.println(n);  // List의 각 요소를 순차적으로 처리
}
```
- Iterable 인터페이스를 구현한 객체들(List, Set 등)을 순차적으로 반복할 수 있다. 
- Iterable 객체를 반복해서 각 요소를 하나씩 처리한다.


<br>

#### 2. Stream
```java
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);

// Stream을 사용하여 처리
numbers.stream()
       .filter(n -> n > 2)  // 2보다 큰 숫자만 남기기
       .map(n -> n * 2)     // 각 숫자에 2를 곱하기
       .forEach(n -> System.out.println(n));  // 결과 출력
```
- 데이터를 단방향으로 처리
- 파이프라인 형식으로 데이터 처리
- Stream은 데이터를 한 번만 소비할 수 있고, 반복문을 사용하지 않고 데이터를 처리한다.


### Iterable의 추상 메소드를 모두 구현하고 있지만 extend는 하지 않는다.  
Iterable는 자바에서 for-each 문과 호환되는 인터페이스로, 내부에 iterator() 라는 메서드를 가지고 았어 반복을 가능하게 한다.

Stream은 iterator 메서드를 가지고 있지만 Iterable를 상속하지 않는다.


동작은 하지만 직관성이 떨어진다.

  
어댑터 메서드를 사용하자.


### 어댑터 메서드
- 하나의 클래스의 인터페이스를 클라이언트에서 사용하고자 하는 다른 인터페이스로 변환한다.
- 이를 통해 인터페이스 호환성 문제가 있는 클래스를 연결해서 사용할 수 있다. 
- 어댑터 메서드 안에서 다로 형 변환을 하지 않아도 된다.
```java
public static <E> Iterable<E> iterableOf(Stream<E> stream) {
	return stream::iterator;
}
```
```java
public class Test {
  public static void main(String[] args) {
    Stream<String> snacks = Stream.of("오레오오즈", "콘칲", "닭다리스낵");

    for (String snack : iterableOf(snacks)) { // 어댑터 메소드 사용
      System.out.println(snack);
    }
  }
}
```



- 스트림 파이프파인 안에서 사용된다면 -> Stream
- 반복문에서만 사용된다면 -> Iterable
- Collection은 Iterable의 하위 타입인 동시에 Stream을 반환하는 메서드를 제공한다.
  - 원소 시퀀스를 반환하는 공개 API 반환 타입에는 Collections이나 그 하위 타입을 쓰는게 최선이다.
  - Arrays -> Arrays.asList(), Stream.of()

원소의 갯수가 많아진다면 전용 컬렉션을 고려하자.
- 입력 집합의 멱집합(한 집합의 모든 부분집합을 원소로 하는 집합)을 전용 컬렉션에 담아 반환
```java
public class PowerSet {
    public static final <E> Collection<Set<E>> of(Set<E> s) {
        List<E> src = new ArrayList<>(s);

        if (src.size() > 30) {
            throw new IllegalArgumentException("집합에 원소가 너무 많습니다(최대 30개).: " + s);
				}

        return new AbstractList<Set<E>>() {
						@Override 
						public int size() {
                return 1 << src.size();
            }

            @Override 
						public boolean contains(Object o) {
                return o instanceof Set && src.containsAll((Set)o);
            }

            @Override 
						public Set<E> get(int index) {
                Set<E> result = new HashSet<>();
                for (int i = 0; index != 0; i++, index >>= 1)
                    if ((index & 1) == 1)
                        result.add(src.get(i));
                return result;
            }
        };
    }
}
```
