### 가변인수?
명시한 타입의 인수를 0개 이상 받기 위해 사용한다.
메서드 호출 시, 인수의 갯수만큼의 사이즈를 가진 배열을 만들고, 이를 배열에 저장하여 메서드를 건내준다.  



### 인수를 0개 넣어 호출하면?

```java
static int min(int... args) {
	if (args.length == 0) {
		throw new IllegalArgumentException("인수가 1개 이상 필요합니다.");
	}
	int min = args[0];
	for (int i = 1; i < args.length; i++) {
    if (args[i] < min) {
      min = args[i];
    }
	}
	return min;
}

sum(); // error
```
인수를 0개만 넣어서 호출하면 런타임에서 실패한다.  
args는 가변 인수로, 호출 시 전달된 모든 인수를 배열 형태로 받는데, 만약 아무 인수도 전달되지 않으면 길이가 0인 배열로 초기화된다.

min의 초기값을 설정하지 않고 for-each를 사용할 수 없는데, 그 이유는 첫 번째 요소를 초기화하는 동작을 처리하기 어렵기 때문이다. 
배열의 첫 번째 요소를 초기값으로 사용하려면 일반 for 문을 사용하는 것이 더 적합하다.  


<br><br>


이런 문제는 매개변수를 2개 받도록 하면 사라진다.  

```java
static int sum(int firstArg, int... remainingArgs) {
	int min = firstArg;
	for (int arg : remainingArgs) {
		if (arg < min) {
      min = arg;
    }
	}
	return min;
}
```

가변이인수의 등장으로 printf가 등장했고, 리플렉션 기능도 재정비 되었다. 


가변인수 메서드는 호출될 때마다 배열을 새로 하나 할당하고 초기화한다.
