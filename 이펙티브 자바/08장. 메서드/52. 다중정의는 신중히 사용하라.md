

**재정의한 메서드는 동적으로 선택되고, 다중정의한 메서드는 정적으로 선택된다.**



오버라이딩은 객체가 실제로 어떤 클래스인지에 따라 실행되는 메서드가 결정된다. 즉, **런타임(동적)** 에 선택된다.
```java
class Parent {
    void sayHello() {
        System.out.println("hello Parent");
    }
}

class Child extends Parent {
    @Override
    void sayHello() {
        System.out.println("hello Child");
    }
}

Parent obj = new Child(); // Parent 타입이지만 실제 객체는 Child
obj.sayHello(); // hello Child
```

다중정의된 메서드는 메서드를 호출할 때 전달하는 인자에 따라 메서드가 결정된다. 
**컴파일 시점(정적)** 에 어떤 메서드를 호출할지 결정된다.
```java
class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }
}

Calculator calc = new Calculator();
System.out.println(calc.add(1, 2));       // 3
System.out.println(calc.add(1.5, 2.5));   // 4.0
```




---

다른 개수의 파라미터에만 오버로딩을 정의하거나, 오버로딩 대신 메서드의 이름을 달리하여 다중정의를 흉내내자.
