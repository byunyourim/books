### 메서드 레퍼런스의 유형
|No|메서드 참조 유형|예|같은 기능을 하는 람다|
|:---:|:---:|:---:|:---:|
|1|**정적 메서드를 가리키는 메서드 참조**|Integer::parseInt|str -> Integer.parseInt(str)|
|2|**한정적 메서드 참조**|Instant.now()::isAfter|Instant then = Instant.now(); <br/> t -> then.isAfter(t)|
|3|**비한정적 메서드 참조**|String::toLowerCase|str -> str.toLowerCase()|
|4|**클래스 생성자를 가리키는 메서드 참조**|TreeMap<K, V>::new|() -> new TreeMap<K,V>()|
|5|**배열 생성자를 가리키는 메서드 참조**|int[]::new|len -> new int[len]|

#### 한정적 참조
- 특정 객체에 바인딩되어 해당 객체의 메서드를 참조한다. 
- `인스턴스::메서드이름`
- 참조 대상이 특정 객체로 고정되며, this나 특정 인스턴스를 사용해 메서드를 호출한다.
  
#### 비한정적 참조
- 참조 대상 객체를 정하지 않고 메서드를 참조한다.
- `클래스명 :: 메서드 이름`
- 참조 대상 객체는 메서드를 호출할 때 전달되며, 호출 시 참조 대상이 필요한다.
